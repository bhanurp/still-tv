# Still TV v0.3.0

A more useful Home screen, rotating headers and less repeated artwork work. This release keeps the native Android TV interface, saved favorites and original-launcher recovery.

## Home and appearance

- Replaces the large morning/evening greeting with a compact connection, available internal-storage and date strip. Favorites sit higher on the screen.
- Observes Ethernet, Wi-Fi or VPN state through Android callbacks while Home is visible. Distinguishes validated internet, unverified access, sign-in requirements and offline state.
- Checks storage on the existing background worker when Home resumes, with no status polling timer, extra worker thread or online feed.
- Rotates through 19 approved two- or three-word phrases, including “Netflix & Chill,” “Press Play” and “One More Episode.” Immediate repeats are excluded, including across process restarts. “Escape the Ordinary” is excluded.
- Uses 32 sp DM Sans for the left header and retains the 36 sp clock. Theme and accent previews preserve the current phrase. Dark, Super Dark and Light themes, three accents and Neon amber as the default remain available.

## Responsiveness

- Uses exact package-version timestamps in artwork filenames, fixing cache misses caused by the TV rounding file timestamps to whole seconds.
- Reuses unchanged app objects, banners and grid views, preserving focus and avoiding placeholder flashes on unchanged refreshes.
- Delivers artwork before PNG compression; completed cache files are renamed from temporary files. Stale cache entries and individual oldest files are pruned within the existing budget.
- Updates accent colors without rebuilding the screen or resetting scroll.

On one Sony Android 11 TV, the local-status comparison measured seven fresh-process launches per build: median 642 ms before and 560 ms after. A 100-key navigation sample recorded 800 frames: p95 was 8.54 ms before and 9.06 ms after, with 1 and 0 frames respectively above 16.67 ms. These are small, unrandomized samples, not a universal speedup or zero-jank guarantee. See [PERFORMANCE.md](../../PERFORMANCE.md) and the [local-status evidence](../evidence/local-status.json).

## Upgrade and recovery

Android versionName is **0.3.0**, versionCode **5**. The APK uses the existing signing key and updates v0.1.0/code4 and earlier previews without removing app data:

```sh
adb -s TV_SERIAL install --no-incremental -r still-tv.apk
```

The original launcher stays installed. **Settings → Restore original launcher** and the independent [ADB recovery tool](../../RECOVERY.md) remain available. Keep the original launcher installed; use recovery if Home becomes unusable.

The one normal permission is `ACCESS_NETWORK_STATE`, used to read connection state. The launcher does **not** request `INTERNET`; there are no OTT feeds, ads, analytics or account service. Storage and date refresh when Home resumes. Connection state reflects Android validation, not a measured internet speed.

## Validation

- 26 existing state checks, 7 connection-state cases, 1,000 seeded phrase reloads and 12 recovery tests passed.
- Signed APK build and independent code review completed.
- Real-TV probes checked all 19 phrases fit, 32/36 sp header sizes, compact status/date layout, actual Ethernet capability delivery, simulated offline callback handling, stale callbacks after stopping, cleanup and restoration.
- Unchanged refreshes retained banners/focus; accent preview retained scroll. Six favorites and actual default Home resolution were preserved; Sony Home remained installed.
